Visual direction:
Modern collegiate athletics + broadcast graphics + management sim.

Theme:
Dark-first.

Character:
Competitive, serious, data-rich, polished.

Avoid:
Generic SaaS dashboards.
Purple gradients.
Excessive rounded cards.
Huge empty whitespace.
Sportsbook/gambling aesthetics.
Direct ESPN/NCAA visual imitation.

Typography:
Condensed sports display typography + readable data sans.

Layout:
Desktop-first.
Dense tables.
Strong hierarchy.
Scores are visually dominant.

Team branding:
Use restrained team accent colors.
Demo branding belongs to the presentation layer for now.

Motion:
Subtle and functional.

Current screens:
Pregame matchup
Roster/rotation viewer
Postgame final score
Box score

Not current:
Season
Recruiting
Rankings
Tournament
Coach profile
Dynasty dashboard

The matchup/final-score area should borrow visual language from an arena center court / broadcast scoreboard, without directly imitating ESPN or NCAA branding.
